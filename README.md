# 群組活動布告欄

給 LINE 群組用的活動布告欄。成員在 LINE 裡打開網頁，就能發起活動、報名、留言、打卡簽到，不用另外裝 App。

**不需要伺服器、不需要資料庫、不需要付費。** 資料存在你自己的 Google 試算表，隨時可以打開來看或手動修改。

---

## 功能

**活動**

- 發起揪團、報名／取消、活動留言
- 三種類型：一般揪團、固定團（每週固定時間、沒有結束日）、許願團（湊不到人就自動消失）
- 交棒主揪、加強推廣（同時最多 3 個）
- 一鍵複製活動資訊或 `@成員` 標記，貼回群組
- Google 日曆自動同步，成員可訂閱到自己的日曆

**打卡簽到**

- 成員自己登記，第一次登記自動加入名單
- 管理員勾選「打卡成功」確認，兩層權限分開
- 名單可搜尋、依名稱排序、依打卡狀態篩選
- 一鍵複製未打卡成員的 `@名字` 去群組催人

**管理**

- 管理員模式（密碼驗證，入口藏在頁首版本號）
- 可編輯／刪除任何活動、移除成員、重置全部打卡
- 所有操作寫入 `AuditLog`，過期活動每天自動歸檔

**其他**

- 前端改版後，已開著的頁面 60 秒內自動更新
- 網路不穩時操作會保留並自動重試，不會默默消失

## 怎麼架設自己的一份

1. 按 **Use this template** 建立你自己的倉庫（沒有這顆按鈕就用 Fork）
2. 照 **[SETUP.md](SETUP.md)** 一步一步做，大約 40 分鐘

> **最重要的一步：** 一定要改 `index.html` **最上面** `SITE_SETUP` 區塊的四個值。
> 沒改的話你的活動與打卡資料會寫進原作者的試算表。
> 程式有防呆——沒改就會整頁顯示「這個網頁還沒設定完成」，不會連線也不會寫入。

## 專案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 整個前端，HTML + CSS + JavaScript 全在這一個檔案 |
| `version.json` | 版本清單，讓已開啟的頁面自動更新 |
| `gas/Code.gs` | Google Apps Script 後端，貼進 Apps Script 編輯器 |
| `gas/README.md` | 表格欄位、部署、日曆與歸檔說明 |
| `SETUP.md` | 從零架設的完整步驟 |
| `AGENTS.md` | 維護規則與踩雷紀錄，改程式前建議先讀 |

架構是「單一 HTML 前端 + Apps Script 後端 + Google 試算表資料庫」。前端由 GitHub Pages 發布，後端部署成 Apps Script 網頁應用程式，兩邊各自獨立更新。

---

## 已知限制

- **Apps Script 會把同時進來的請求排隊。** 實測 6 個併發請求，每個腳本內部只跑 1～2 秒，但 HTTP 各等了 25～77 秒。所以前端刻意把自動同步降到 60 秒一次，不要為了「即時感」調回十幾秒，那會把整個群組一起拖慢。
- 打卡名單上限 500 人（對齊 LINE 群組人數上限）。
- 打卡不保留歷史，只記「本輪有沒有成功」，也不會換月自動重置。

細節與實測數據都在 `AGENTS.md`。
